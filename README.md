# MHCI Task Tracker

A sophisticated, executive-grade task management system designed for seamless collaboration between CEOs and their assistant teams.

## Key Features

### 1. Executive Task Delegation
*   **Create Task Workflow**: Dedicated interface for rapid task creation with priority leveling (H/M/L) and category sorting (Weekly/Monthly).
*   **Assistant Assignment**: Direct delegation to specific assistants with integrated avatar previews and ownership tracking.
*   **Pending Review Module**: High-visibility dashboard module for the CEO to oversee and "signal" pending activities.

### 2. AI Strategic Intelligence (AI Strategy Lab)
*   **AI Insights**: One-click strategic analysis for any task, providing executive summaries and tactical recommendations.
*   **Global Load Analyzer**: Heuristic analysis of the entire week's workload to identify strategic concentrations and risks.
*   **Intelligent Allocation**: AI-driven suggestions for which assistant is best suited for a specific task based on expertise.

### 3. AI System Configuration
*   **Multi-Model Support**: Integrated support for **Gemini**, **OpenAI**, and **Claude**.
*   **Secure API Management**: Secure configuration portal with masked inputs and test connection capabilities.
*   **Usage Control**: Granular model selection and token usage caps for cost management.

## Design System
*   **Executive Monochrome**: A strictly minimal, high-contrast palette (Charcoal, White, Gray) designed for clarity, focus, and an authoritative "Swiss" editorial aesthetic.
*   **Inter Typography**: Optimized for high-density data display and legibility.
